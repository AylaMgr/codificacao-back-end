# Codificação para Back-End

## 📌 Sobre o Projeto
Este repositório é destinado ao armazenamento de códigos, exercícios, projetos e materiais práticos desenvolvidos durante a Unidade Curricular de **Codificação para Back-End**.

---

## 🎯 Objetivos do Curso
- Compreender os fundamentos e a arquitetura de sistemas web no modelo Cliente-Servidor.
- Construir APIs RESTful eficientes, organizadas e escaláveis.
- Implementar regras de negócio, validação de dados e segurança nas aplicações.
- Manipular bancos de dados relacionais e não-relacionais integrados ao servidor.

---

## 🛠️ Tecnologias Aplicadas
- **Linguagem / Ambiente de Execução:** Node.js / JavaScript / TypeScript
- **Frameworks Web:** Express.js
- **Banco de Dados:** PostgreSQL / MySQL / MongoDB
- **Comunicação:** Protocolo HTTP, Padrão REST, Formato JSON

---

## 🧰 Ferramentas Utilizadas
- **Editor de Código:** Visual Studio Code (VS Code)
- **Controle de Versão:** Git e GitHub
- **Testes de API:** Postman / Insomnia
- **Gerenciador de Pacotes:** npm
